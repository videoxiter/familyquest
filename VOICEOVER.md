# Голоса семьи — что записано и как добавить

## Что сделано

Все реплики синтезированы локально в **Speech Studio 0.5.1** движком **Higgs Audio v3**
на клонированных голосах **Евгений Яковлев**, **Мама**, **Алёша**.
Скрипт: `scripts/studio-voices.py`. Файлы: `public/audio/voice/` — 36 штук, ~2.8 МБ, 24 кГц моно.

### Настройки качества, которые использовались

| Параметр | Значение | Почему |
|---|---|---|
| Движок | Higgs Audio v3 | на нём сделаны сами голоса — тембр сохраняется |
| Язык | `ru` | автоударения включены (`auto_stress`) |
| temperature | 0.7 | чуть ниже дефолта: стабильнее произношение коротких фраз |
| top_k / top_p | 30 / 0.85 | убирает «прыгающую» интонацию |
| seed | fixed 42 | одна и та же реплика звучит одинаково при перегенерации |
| loudness | video | ровная громкость между файлами |
| нормализация | вкл. | громкость не скачет между репликами |
| QC / ASR-проверка | выкл. | на выкриках вроде «Умничка!» распознавание даёт ложные провалы |

## Как устроены имена

```
<событие>-<линия>-<говорящий>.wav
task_done-1-papa.wav     task_done-2-alyosha.wav
```

- **линия 1** — первая реплика из пары, **линия 2** — вторая;
- каждый участник слышит **двух других**: первый говорит линию 1, второй — линию 2;
- свой голос человек не слышит никогда.

Поэтому папе нужны только первые линии (его слушают как «первого»), Алёше — только вторые,
а маме — обе (для папы она первая, для Алёши — вторая). Итого 36 файлов вместо 54.

## Реплики

| Событие | Линия 1 | Линия 2 |
|---|---|---|
| `task_done` | Вот это да! | Как у тебя это получилось? |
| `task_claimed` | Вот это задачка! | Ну попробуй! |
| `task_approved` | Умничка! | Всё сделано! |
| `task_rejected` | Не жульничай! | Так это не делается! |
| `task_late` | Лучше поздно, чем никогда! | Главное, что готово! |
| `level_up` | У тебя новый уровень! | Поздравляю! |
| `achievement` | Новый значок, круто! | Неплохо смотрится! |
| `streak_7` | Семь бед — один ответ! | Целую неделю! Это характер! |
| `daily_reminder` | Не забудь, время подходит! | Осталось так мало времени! |

У обмена приза звучит только короткая музыкальная отбивка, без голосов — как и просили.

## Добавить или переписать реплику

1. Правь список `PHRASES` в `scripts/studio-voices.py`.
2. Запусти только нужного говорящего:

```bash
python scripts/studio-voices.py --speaker mama
```

Скрипт создаст проект в студии, озвучит, выгрузит посегментно и перезапишет файлы
с правильными именами.

Если добавил файлы вручную (например, записал своим голосом) — просто положи их
с такими же именами и выполни `npm run voices` (соберёт `manifest.json`).

## Проверить на телефоне

«Прогресс» → **Звук** → «Проверить звук»: проиграет отбивку награды и реплику `task_done`
двумя голосами других участников. Переключатели музыки и звуков независимые.
