# Правила для агентов в этом проекте

## Язык общения — строго русский

- Весь текст для пользователя (сообщения, отчёты, объяснения) — **только на русском**.
- Английский допустим для технических обозначений: имена файлов и функций, SQL, API,
  названия сервисов. Английские фразы в отчётах — дефект.

## Что это за проект

- Семейный трекер задач: SPA (React + Vite + TS + Tailwind) на GitHub Pages,
  бэкенд целиком в Supabase (Postgres: RLS + RPC + pg_cron).
- Своего сервера нет. Вся бизнес-логика — в SQL (`supabase/migrations`).
- Документы: [README.md](README.md) — установка и правила игры, [DESIGN.md](DESIGN.md) —
  разбор идеи и архитектура.

## Жёсткие правила

1. **Никогда не читать и не передавать `.env`, `.env.local`** и любые файлы с ключами.
   Для примеров есть `.env.example`.
2. `service_role` в браузерном коде не используется. Только anon-ключ + JWT + RLS.
3. Запись в домен — только через `security definer` RPC. Не добавлять INSERT/UPDATE-политики
   на `assignments`, `ledger`, `redemptions` для `authenticated`.
4. Изменил файл в `supabase/migrations` → обязательно `npm run sql:bundle`
   (CI проверяет, что `apply_all.sql` не устарел).
5. Журнал `ledger` неизменяем. Отмена — обратная транзакция.

## Проверка перед отправкой ответа

```bash
npm test          # типы + smoke-тест миграций на PGlite
npm run build     # сборка
```

1. `npm test` зелёный.
2. Ответ полностью на русском.
3. Действия названы так, как есть: «сделано», «запушено», «нужно сделать тебе» — без вымысла.
